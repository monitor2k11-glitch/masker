Help

Simple CSV: one column, Column Name. Starter rules are attached to known category names. Advanced CSV: Category,Description,Enabled,MatchMode,CaseSensitive,Values,Patterns; separate multiple items with | and escape a literal pipe as \|.

Match modes: exact matches whole values, regex/contextual use patterns. If a pattern has capture groups, only the last participating group is masked (the label stays); otherwise the whole match is replaced. A leading (?i) is converted to the case-insensitive flag.

Overwriting files needs the File System Access API (Edge/Chrome, served from https:// or http://localhost; file:// often works too). Without it, scanning works and masked files download instead. Run python -m http.server in this folder if needed.

Overlaps: the longest match wins; ties go to the category listed first. Overlapping losers are counted as conflicts and not applied.
